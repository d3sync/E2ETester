# Adoption and CI increment

Implement in order: documentation correction and first-run protocol; measurable synthetic business workflow; Postman 2.1 and OpenAPI YAML/reference imports; headless execution and JSON Schema assertions.

Acceptance: no silent loss of imported scripts/authentication, no API execution during import, bounded parsing, CI exit codes and JUnit plus canonical evidence, explicit incomplete outcomes, reuse of existing preparation/restoration rules, offline schema evaluation. Verify with integration tests and a fresh isolated desktop workspace.

Human validation remains separate: ask a tester who has never used the app to follow docs/first-run-study.md and record assistance, completion time and errors. Automated smoke tests cannot certify this usability result.
