Evidence-first, not request-first
A calmer way to test

Explore safely. Keep what mattered.

Packages carry instructions, defaults, assertions and editable cases. Nothing is sent just by opening a package.

01 / PREPARE

Reusable test packages

Package endpoints, variables, headers, bodies and assertions into a test flow people — and agents — can repeat.

02 / RUN

Guided variations

Run one case at a time. Edit safely, add a variation when needed, and distinguish PASS, FAIL and INCONCLUSIVE.

03 / PROVE

Evidence that travels

Export JSON or HTML reports, redacted cURL and evidence bundles for a teammate, a ticket, or your next self.

Built for real environments

From Swagger sign-in to database verification.

Identity-aware

Use remembered browser sessions, JWT/API tokens, OIDC/PKCE and named identities without turning a test run into a credential hunt.

Deep when required

Optional SQL Server, MySQL, PostgreSQL and SQLite fixtures and verification give a request its real-world context.

Agent-ready

Ship MCP stdio tools and structured reports alongside local-first workspace recovery, backups and saved runs.

Updates & rollback

Signature verification

Verify the publisher before installing.
