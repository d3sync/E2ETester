# Code of conduct

Treat contributors and users with respect. Discuss the work, explain disagreements with evidence, and make room for different experience levels. Constructive criticism is welcome; harassment, threats, discrimination, doxxing and unwanted sexual attention are not.

Respect privacy. Never share someone else's credentials, personal information or private test evidence. Ask before moving a private conversation into a public issue.

Maintainers may edit or remove harmful content, pause a discussion, or restrict participation. They should explain decisions where doing so does not compromise privacy or safety, and apply these rules consistently.

Report problems privately to a repository maintainer using an available private contact channel. If none is published, ask for a private contact method without posting sensitive details. This policy applies to project-managed issues, pull requests, discussions and events.
